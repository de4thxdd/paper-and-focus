# Paper & Focus - deployment

This package is prepared for a Render web service.

## Render
- Connect the GitHub repository.
- Render will detect `render.yaml`.
- The service uses a persistent disk for `server/data`, where SQLite lives.
- `JWT_SECRET` is generated by Render.

## Commands
Build: `npm ci && npm run build`
Start: `npm start`

Do not commit `server/data/diary.sqlite`, `.env`, or `node_modules`.
